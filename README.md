# Skills-Canada-2026
Designed, built, and programmed two tele-operated robots and one autonomous robot over a period of nine months for the 2026 Skills Canada Mobile Robotics competition. Acted as a team leader, delegating tasks and making major design decisions. While focused mainly on design and gameplay strategy, I also played a key role in developing several versions of precise autonomous navigation systems using various sensors and feedback loops, as well as a separate macro program for autonomous testing. Implemented control algorithms to improve navigation accuracy and robot performance, while iteratively refining mechanical and software systems through testing and competition experience. Represented British Columbia at the 2026 Skills Canada Nationals in Toronto, having won both regional and provincial gold medals.
